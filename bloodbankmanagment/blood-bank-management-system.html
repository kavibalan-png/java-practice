About this environment

This is a self-contained front-end demo. All data lives in memory for this session (donors, inventory, queues) and resets on reload — there is no database connected here.

A matching Spring Boot + MySQL backend scaffold (entities, repositories, HashMap/Queue/PriorityQueue services, REST controllers, schema.sql) is provided separately for real deployment.
